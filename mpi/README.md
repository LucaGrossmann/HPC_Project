# `mpi/` — Part 3: distributed-memory MPI

Distributes the per-slice SVD loop across ranks. Each rank holds the
full tensor (read independently from disk), runs the forward mode-3
`dgemm` on all of it, then computes SVDs only on its `n / P` slab.
Three `MPI_Allgather` calls reassemble `U_hat`, `s_hat`, `V_hat^T`;
the inverse mode-3 transforms run redundantly on every rank.

This redundancy keeps the SVD step communication-free at the cost of
duplicated mode-3 compute. Strong scaling tops out at ~2× over the
medium fixture; see report §3.2 and §3.3.

## Layout

| File | Role |
|---|---|
| `tsvdm_mpi.cpp` | MPI-distributed version of the serial source. Each rank reads the full fixture, runs the full mode-3 forward DGEMM, calls `sliceSvdAll` on its `n/P` slab, then 3× `MPI_Allgather` reassembles `Uhat`/`sHat`/`VtHat` before the redundant inverse mode-3. |
| `Makefile` | mpicxx (wraps g++ 11.5) with `-O3 -march=native -std=c++17`, Spack OpenBLAS via `-Wl,-rpath`. |
| `submit.slurm` | Strong-scaling sweep over `P ∈ {1, 2, 4, 8}` (one rank per node); accepts a `P_LIST` env override and a positional fixture path. |
| `weak.slurm` | Weak-scaling sweep: `P ∈ {1, 2, 4, 8}` paired with `n = 32·P` from the `weak_n*.bin` fixtures so per-rank slice count stays at 32. |
| `results/` | Per-Slurm-job stdout and the per-impl scaling plots (`mpi_strong.pdf`, `mpi_weak.pdf`) generated by `report/plot_scaling.py`. |

## Run

```bash
[cluster]$ cd mpi
[cluster]$ sbatch submit.slurm                              # default: medium fixture
[cluster]$ sbatch submit.slurm ../serial/fixtures/large.bin # large
[cluster]$ sbatch weak.slurm                                # weak scaling
[cluster]$ sbatch --export=ALL,P_LIST="8" submit.slurm ...  # isolate P=8
```

`OPENBLAS_NUM_THREADS=1` ensures MPI is the only source of
parallelism. The `--export=ALL,P_LIST=...` override gives any single
rank count its own 10-min budget when needed (large + P=8 has been
known to brush the wall cap).
