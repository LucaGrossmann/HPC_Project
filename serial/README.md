# `serial/` — Part 1: serial C++ baseline

Single-threaded LAPACK reference implementation of t-SVDM. Establishes
the wall-time baseline against which OpenMP, MPI, CuPy, and Julia are
compared.

## Layout

| File | Role |
|---|---|
| `tsvdm_serial.cpp` | Algorithm core in one file: `loadFixture`, `modeThree` (one DGEMM for both forward/inverse), `sliceSvdAll` (per-slice DGESDD with shared workspace), `reconstructApprox`, `relativeError`. Times 30 reps. |
| `Makefile` | g++ with `-O3 -march=native -std=c++17`, Spack OpenBLAS via `-Wl,-rpath` so the binary resolves `libopenblas.so` at job time. |
| `submit.slurm` | Single-rank, single-thread benchmark. Pins `OPENBLAS_NUM_THREADS=1`, builds in-job (`make -s -B`), takes a fixture path as the first positional arg. |
| `gen_fixtures.slurm` | One-shot job that calls `cuda/gen_fixture.py` to populate `fixtures/` with all seeded `.bin` tensors used by the C++ backends. |
| `fixtures/` | Committed `.bin` tensors: `small.bin` (64³), `medium.bin` (256³), `large.bin` (512×512×256), and `weak_n{32,64,128,256,512}.bin` for the weak-scaling sweep. |
| `results/` | Per-Slurm-job stdout (`tsvdm_serial-<jobid>.out`) plus `serial_size_scaling.pdf` generated by `report/plot_scaling.py`. |

## Data layout

`A` is shape `(m, p, n)` column-major (Fortran order); each frontal
slice is a contiguous `m * p` block passed directly to `dgesdd`.
`M` is `(n, n)` column-major. Fixtures encode this layout, written by
`cuda/gen_fixture.py`.

## Build & run on the cluster

```bash
[cluster]$ . ~/161588/spack/share/spack/setup-env.sh
[cluster]$ spack env activate -p CS-2050
[cluster]$ cd serial && sbatch submit.slurm fixtures/medium.bin
```

`submit.slurm` builds in-job (`make -s -B`) and pins
`OPENBLAS_NUM_THREADS=1`. Output line format is identical across all
five backends:

```
m=256 p=256 n=256 reps=30 rel_err=3.585e-15 median_ms=4269.736 ...
```

Override the fixture as the first positional arg; default is
`fixtures/small.bin`.
